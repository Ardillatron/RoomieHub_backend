# ADR-004: Acciones inmediatas y acciones que pueden esperar

**Estado:** Aceptado

## Contexto

Algunas cosas necesitan respuesta al momento y otras pueden esperar a que vuelva el internet.

## Decisión

Lo normal se hace al momento. Lo hecho sin internet se guarda y se envía después. Cada acción lleva un número único para que no se guarde dos veces.

## Alternativas descartadas

- Todo al momento: sin internet no se podría hacer nada.

## Consecuencias

- A favor: La app no se bloquea sin internet.
- En contra: Hay dos formas de enviar datos que mantener.
